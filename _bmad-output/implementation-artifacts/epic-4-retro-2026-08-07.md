## What Went Well

- **The AD-16 amendment held up exactly as intended.** Epic 3's retro anticipated Story 4.2's drag-drop-plus-clipboard-paste shape and wrote the exact required pattern (`registry.getLatestWinsRunner(toolId)`, citing `HashView.vue`) into the spine before Story 4.1 even branched. When Story 4.2 needed it, it worked without rediscovery — the clearest example yet of a retro action item closing the loop.
- **Full scope delivered on the project's most novel epic so far.** First bundled ML dependency, first Tauri resource bundling, first lazy-singleton pattern, first command needing `AppHandle`, first raw-IPC-body command — and FR23–FR26 still shipped with zero descoping.
- **Fresh-context validation caught real bugs before merge, twice.** Story 4.1's originally-proposed race test would have been a no-op (racing a shared static other tests had already initialized); Story 4.2's independent review caught three real gaps, including a raw-IPC-body test-construction problem with no existing pattern to copy.
- **The privacy promise (AD-7/NFR1) is now proven for the Bucket, not just assumed** — automated dependency-absence audit plus a live `nettop` capture during this retrospective closed AC4's manual half in real time.

## Challenges

- **Dependency version/API drift recurred for a third straight epic**, and twice within Epic 4 alone: `oar-ocr` moved from the spine's documented 0.8.x pin to 0.9.0 in the 24 hours before Story 4.1 started, then turned out to resolve to 0.6.3 under this project's MSRV — two layers of drift in one story. A second, independent instance one dependency deeper: `oar-ocr-core` declared `ort = "2.0.0-rc.12"` but Cargo resolved `rc.13`, which had renamed a type and broke the build. The mitigation (verify against vendored source, not docs.rs) has worked every time it's been applied — but it's been re-derived from scratch in each story's own Dev Notes rather than living as a standing rule.
- **Two real architectural gaps surfaced mid-story that neither the epics nor the spine anticipated in detail:** clipboard `readImage()` delivers already-decoded raw RGBA pixels, not compressed bytes (Story 4.2), and an `async fn` taking a borrowed `tauri::ipc::Request` can't satisfy Tauri's `Send + 'static` bound for async responses (Story 4.2, tauri-apps/tauri#2533). Both were resolved cleanly, but both were real gaps in the pre-story research, not implementation bugs.
- **Epic 3's low-priority doc-hygiene action item (stale `addendum.md` references in `epics.md`/PRD) is now two epics old**, correctly not touched during Epic 4 since it isn't Bucket-related, but it keeps losing to real feature work.
- **A significant discovery nearly required an Epic 5 replan mid-retrospective:** the developer initially wanted to defer the $99/year Apple Developer ID purchase and explore an unsigned/Windows-first interim release, which would have conflicted with Epic 5's current macOS-signed-first plan and the PRD's own FR30/NFR3 priority call. Resolved within the same session — the developer decided to purchase the certificate now, at MVP stage, since one year of membership comfortably covers MVP through v1/v2. No epic rewrite needed, but it's a reminder that Epic 5's plan rests on an assumption (certificate timing) that hadn't been explicitly confirmed with the developer before this retro.
