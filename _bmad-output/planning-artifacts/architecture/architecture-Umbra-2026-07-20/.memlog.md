- (decision) Paradigm is functional core, thin shell (Bernhardt pattern): umbra-core crate is the functional core (pure transformations, zero IO, zero Tauri deps), src-tauri is the thin imperative shell (all OS IO, Tauri commands), src (Vue) is the presentation shell (view-owned locale and timezone formatting, Pinia stores for cross-cutting state).
- (decision) AD-1. Binds: all tool logic. Prevents: business logic leaking into src-tauri or Vue where it cannot be unit tested or reused across platforms. Rule: every transformation is a pure function in umbra-core; presentation formatting such as locale and timezone rendering is view-owned, never computed in core.
- (decision) AD-2. Binds: umbra-core crate. Prevents: a macOS-only dependency or platform branch silently breaking the NFR3 cross-platform-clean promise. Rule: umbra-core imports no tauri or tauri-star crate and contains zero cfg target_os branches; CI enforces this per AD-11.
- (decision) AD-3. Binds: every Tauri command. Prevents: each tool inventing its own error shape, forcing the view to string-match messages. Rule: a single ToolError type (code as a stable kebab-case string, message, position as an optional LineCol or ByteOffset, context), defined once in umbra-core, is the only error every command returns as Result of T and ToolError; commands are named tool underscore verb; the view renders errors from structure only, never by parsing message text.
- (decision) AD-4. Binds: any tool operation. Prevents: the UI freezing on large inputs or heavy first-use initialization. Rule: work that can exceed about 100ms CPU runs async on the Rust blocking thread pool; large result sets render through virtualized views; heavy resources such as the OCR session initialize lazily on first use, never at launch.
- (decision) AD-5. Binds: sidebar, command palette, routing. Prevents: tool metadata drifting across three separately maintained lists. Rule: one Tool Registry entry (id, name, aliases, route, icon, drop and shortcut declarations) is the single source that generates the sidebar, the palette index, and the route table; nothing else enumerates tools.
- (decision) AD-6. Binds: cross-tool state. Prevents: tools coupling to each other and becoming impossible to add or remove independently. Rule: tools are islands, no tool reads another tool state; cross-cutting state lives only in the Pinia stores named settings and registry.
- (decision) AD-7. Binds: the whole app, per INV-1 and INV-2. Prevents: an untracked network call breaking the local-only promise. Rule: zero network surface except tauri-plugin-updater; no dependency whose purpose is network IO exists anywhere in the tree; webview capabilities grant no network scope; OCR models ship bundled as app resources with oar-ocr auto-download explicitly disabled; the updater carve-out is disclosed in both README and in-app.
- (decision) AD-8. Binds: OCR (Epic 4) and the second AI feature (Epic 6). Prevents: an inference library leaking through the whole call stack instead of sitting behind a swappable seam. Rule: umbra-core owns an OCR-shaped trait (image bytes in, recognized text and confidence out, honest empty and failure states); oar-ocr is the v1 adapter behind it; commands and UI depend on the trait only, never on the adapter crate directly.
- (version) oar-ocr verified 2026-07-20 on crates.io: latest published is 0.2.2 (pre-1.0, versions run 0.1.0 through 0.2.2, released starting 2025-07-31). This corrects the original spine, which cited 0.8.x, a version that appears to never have existed for this crate. Exact API still needs re-verification at Epic 4 start per story 1.1 dev notes, since this is a pre-1.0 crate where minors can break.
- (decision) AD-9. Binds: the NL to cron tool (Epic 3). Prevents: a confident-sounding but wrong cron expression shipping to the user. Rule: every NL-to-cron result round-trips through the cron-to-English direction before display; only a consistent round-trip is shown; the canonical phrase corpus runs as an automated test in umbra-core, and a corpus regression fails the build.
- (decision) AD-10. Binds: all persisted state. Prevents: two writers racing on settings.json or persistence sprawling into an undiscoverable set of files. Rule: the only persistence mechanism is tauri-plugin-store writing one settings.json; the frontend settings Pinia store is its single writer; keys are namespaced shell dot star and tool-id dot star; the Settings pane enumerates every persisted key with a one-action clear; window geometry is captured frontend-side on debounced move and resize events.
- (decision) AD-11. Binds: CI. Prevents: a macOS-only dependency merging unnoticed because the only CI runner is macOS. Rule: cargo check plus clippy run on ubuntu and windows runners on every pull request as required status checks; ort-sys ONNX Runtime binaries are cached in CI once Epic 4 introduces them.
- (decision) AD-12. Binds: releases (Epic 5). Prevents: an unsigned or hand-built artifact circulating, or a secret leaking into the repo. Rule: releases are tag-driven via tauri-action, which builds, signs with the Developer ID certificate, notarizes with Apple, and publishes a versioned GitHub Release including latest.json; the update confirmation dialog is app-built UI, not the updater default; all secrets live only in GitHub Actions secrets; the updater private key is backed up offline in two places before the first release; the NFR1 network-monitor tour result is recorded in every release PR.
- (decision) AD-13. Binds: any future localization. Prevents: a half-localized privacy tool where the UI speaks French but OCR and NL-to-cron still silently expect English. Rule: any release adding a UI language adds that language to the OCR models and the cron grammar plus its corpus in the same release, or the release does not ship.
- (decision) AD-14. Binds: drops, clipboard, keyboard shortcuts. Prevents: every tool wiring its own document-level listener and shortcuts colliding. Rule: the shell owns OS IO edges exactly once; window-level Tauri-native drops dispatch to the active tool registry-declared handler; one clipboard service wraps the Tauri clipboard plugin and navigator.clipboard is forbidden; pasted images dispatch like drops; command-K is one capture-phase handler at app scope; tools register no document-level listeners of their own.
- (decision) AD-15. Binds: file IO. Prevents: raw bytes bloating the JSON IPC bridge or core reaching into the filesystem directly. Rule: files cross the IPC bridge as absolute paths; src-tauri owns all file reads and writes through one shared save-dialog-plus-write helper; umbra-core never touches the filesystem; byte arrays above about 64KB never ride the JSON IPC bridge, with one sanctioned exception for clipboard-pasted image bytes via the raw IPC body.
- (decision) AD-16. Binds: slow command invocations. Prevents: a stale result from a superseded request overwriting a newer one. Rule: one shared frontend invoke helper wraps slow commands with a request id and latest-wins supersession; results for unmounted views are discarded on arrival; the OCR session sits behind a OnceCell so racing first-use initializations share one init; v1 ships no progress events and no cancellation.
