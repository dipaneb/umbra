Umbra — Button/Accent Color Usage on One Real Screen

PDF Merge, sidebar + main pane in one view, so nav accents and in-tool accents can be judged together. One proposed color assignment is applied throughout — lean default: black for most/default actions, orange reserved for the single highest-emphasis primary action plus small marks (active-nav, notification dot) — and every orange or black element is numbered so you can react element-by-element instead of to a rule in the abstract. A few spots deviate from black-or-orange entirely (flagged) where that reads as the more idiomatic choice.

13 numbered elements — orange: #1, #3, #4, #13  ·  black/mono: #5, #6, #7, #10, #11, #12  ·  neutral gray (deliberately not accented): #2, #8  ·  destructive red (deviation, not brand color): #9. Flagged as genuinely uncertain / worth a second look: #3, #9, #11 — see notes under each legend.

#ElementAssignedWhy (one clause)
1Active-nav row, "PDF Merge" (Recent)OrangeThe one always-visible "you are here" mark — orange's most classic sparse job.
2"7 tools" count badgeNeutral grayPure information, not an action — doesn't need to compete with the accent.
3"New" tag, Image Convert flaggedOrangeDraws the eye to a genuinely new item — but is a 2nd orange use beyond nav+dot+CTA.
4Notification dot on settings iconOrangeAn unread-state signal — exactly the sparse, small mark orange is meant for.
5Settings/gear icon buttonBlackDefault utility action, no special emphasis — glyph in near-black, no fill.
6Tab selector, active "Merge"BlackStructural wayfinding between two views, not a call to action.
7Toggle switch, "Keep original files"BlackFunctional on/off state; keeping it out of orange preserves orange's rarity.
8Drag/reorder handle (×3 rows)Neutral grayPure grip affordance — the lowest-priority mark on the row.
9Remove/delete icon (×3 rows) deviationMuted redDestructive convention overrides brand color — red reads as "deletes," neither accent does.
10Drag-and-drop add-files zoneBlackSecondary input affordance, not the screen's one primary action.
11"Choose output folder" text link flaggedBlackKept black to protect orange's single-primary-action meaning — many apps would use accent here instead.
12"Clear all" secondary buttonBlack (outline)Low-emphasis, deliberately quiet next to the primary fill.
13"Merge PDFs" primary buttonOrangeThe screen's one primary action — highest-emphasis fill, where orange should concentrate.
Flagged for a second look: #3 — a second orange use beyond nav+dot+CTA; swap to neutral if orange should stay stricter. #9 — deliberately neither brand color (destructive convention); flag if you'd rather it stay black/neutral instead. #11 — plain links are orange in many systems; kept black here on purpose, easy to flip.
