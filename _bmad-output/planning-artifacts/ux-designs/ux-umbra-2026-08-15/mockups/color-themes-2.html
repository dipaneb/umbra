Umbra — Color Themes (Round 2 — Refinements)

Two refinements from round 1's five variations, built strictly from developer feedback: all dark modes rejected as "inverted" (too close to true black) — rebuilt here with proper Material-style elevation, where raised surfaces get progressively lighter, not darker; card borders rejected as too heavy — removed, with card separation coming from surface-tier contrast alone; "Machined Metal" and "High-Contrast Snap" were the two liked directions and are refined here as Rust Calm and Clean Factory; and a new idea is tested — black (light) / near-white (dark) as a second, achromatic CTA-button accent, so orange stays reserved purely as the sparse signature touch.

1. Rust Calm

Refines "Machined Metal." Same calm, burnt-rust orange register that read as "almost rust" — background kept comfortably not-too-bright, warm charcoal neutrals throughout.

What changed from round 1: dark mode rebuilt from near-black (#0A0A0B base) into a properly elevated warm-charcoal stack — base/surface/surface-2 now step from #141210 up to #272220, each tier lighter, never darker. Card and icon-chip borders removed entirely. Dark-mode accent nudged #C85D1E → #CD6222 so it still clears 4.5:1 as nav-label text against the new, lighter dark base. A near-black (light) / near-white (dark) achromatic CTA fill is introduced for primary buttons — see the button strip below.

2. Clean Factory

Refines "High-Contrast Snap." Same less-red, true amber-orange hue that read as "ChatGPT," "a clean modern app," "a brand new car factory" — now on a cooler, calmer light background.

What changed from round 1: light-mode main background pulled down from near-white (#FFFFFF) to a cool, slightly-tinted gray (#F4F5F6) — borrowed from Precision Titanium's sidebar tone, per feedback. Dark mode rebuilt from near-black (#050505 base) into a properly elevated cool-neutral stack — #141415 → #1D1D1F → #28282B, each tier lighter. Card borders removed. Because this orange is bright enough that neither white nor its own hue clears 4.5:1 as small text on a light background, a separate AA-safe on-light variant (#C04E08) is used for the nav-active label; the brand orange itself is reserved for fills, dots, and icon accents. A black (light) / near-white (dark) achromatic CTA fill is introduced for primary buttons.
