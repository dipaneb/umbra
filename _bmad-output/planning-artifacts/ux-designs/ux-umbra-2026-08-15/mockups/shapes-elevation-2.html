Shapes + Elevation, round 3 — border vs. subtle tonal vs. shadow, light + dark

Round 2's flat/tonal card (#EAEBED fill against the #F4F5F6 page) got rejected as too strong a shift — it read as an obvious gray block, not a subtle stack. This round tests a much subtler tonal lift instead, crossed against a plain hairline-border treatment, at both 4px and 8px radius, so the developer can compare surface treatment and radius independently. A fifth, shadow-based variation is included purely for comparison against convention.

Why variation 5 is here despite the recommendation against it: research on reference apps (Linear) found shadows are conventionally used for floating UI — popovers, modals, toasts — not persistent cards, largely because a soft drop-shadow barely reads against a dark background. Rather than assert that and move on, V5 renders the exact same round-1 shadow at 8px radius in both light and dark mode below, including a rim-glow standing in for the shadow in dark mode, so the tradeoff is visible directly.
How to react: for each variation, compare the light and dark panels together — does the surface still read as "its own region" in dark mode, not just light? V3/V4's tonal lift and V5's shadow are the two treatments where dark-mode behavior is the real test; V1/V2's border should behave identically in both modes almost by construction.

5Shadow, 8px radiuskept for comparison
Kept for comparison only — conventionally used for floating UI (popovers, modals, toasts), not persistent cards; also breaks down in dark mode. Same soft shadow as round 1's V2/V3. In the dark panel, a plain dark drop-shadow would be invisible against the dark page, so it's rendered as a light rim-glow instead — technically the closest working equivalent, but visibly a different, more artificial-looking effect than the clean light-mode version. Compare this panel's dark side against V3/V4's dark side to see the tonal-stacking argument directly.
Light radius: 8px border: none surface: #FFFFFF shadow: 0 1px 2px rgba(16,17,19,.05), 0 3px 8px rgba(16,17,19,.04) padding: 20px
Dark radius: 8px border: none surface: #1D1D1F "shadow" (rim-glow): 0 0 0 1px rgba(255,255,255,.05), 0 1px 0 rgba(255,255,255,.04) inset, 0 8px 20px rgba(0,0,0,.45) padding: 20px
